# streaming_platform

A full-stack streaming platform built with React on the front end and [Node.js/Express | Flask] on the back end. 
Users can browse a catalog, search content, and stream videos directly in the browser through a responsive, 
component-based interface.

## Features
- Browse and search a catalog of videos
- Stream content with a custom video player
- User accounts with sign-up and login
- Responsive design for desktop and mobile
- REST API connecting the React front end to the back end

## Tech stack
- **Front end:** React, [React Router, Tailwind CSS]
- **Back end:** [Node.js, Express]
- **Database:** [MongoDB | PostgreSQL]

## Getting started
git clone https://github.com/Emmanuelkss/streaming_platform.git
cd streaming_platform
npm install
npm run dev
